# Premkumar A Portfolio

Personal portfolio for Premkumar A, built with React, Vite, JavaScript, and CSS.

The site presents my work as a Full Stack Engineer for AI SaaS products, including AlphaTales, Refacta, clawd, InFit, and Focus.

## Stack

- React
- Vite
- JavaScript
- CSS
- GitHub Pages

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

The source code lives on the `source` branch. The `main` branch contains the static GitHub Pages build that serves `https://premkumar2910a.github.io/`.
